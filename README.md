# Gruppo 20, Progetto finale di basi di datirogetto di Simone Gesualdi (S5798663), Francesco Tacchino (S5798607) e Andrea Marotta (S7567638).

Questo progetto universitario implementa il database di una piattaforma tipo "Too Good to Go" pensata per l'ambiente universitario. Il sistema gestisce studenti, offerte, ordini, pagamenti, punti di ritiro, sedi, convenzioni e regole di vincolo legate alla prenotazione, al ritiro e ai no-show.

Nel repository sono presenti lo schema del database, i trigger, gli script di inserimento e le parti del progetto richieste per la consegna finale.
